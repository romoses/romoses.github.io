Privacy policy

Receipts · last updated 22 September 2026

Receipts is a personal command-line tool with a single user: its author, Rodney Moses. There is no hosted service, no account system and no other users. It runs on the author's own computer and acts on the author's own Google account. This policy describes what it accesses and where that data goes.

Google user data it accesses

ScopeWhy it is needed
gmail.modify Read messages in one dedicated receipts mailbox and download their attachments; move handled messages to a label so later runs stay fast. No message is ever sent, and nothing is deleted.
drive Store receipt files in a folder in the owner's Drive, rename them once matched to a bank charge, and read bank export CSVs the owner has placed in a dedicated folder.
spreadsheets Create and maintain one spreadsheet — the ledger recording each bank charge, each receipt, and whether they have been matched.

Where the data goes

  • It stays in the owner's own Google account. Receipt files are written to the owner's Drive; the ledger is a spreadsheet the owner owns. Nothing is uploaded to a server operated by the author, because there is no such server.
  • One exception: Anthropic. To read the date, amount and merchant off a receipt, the image or PDF is sent to the Claude API, operated by Anthropic PBC, and the extracted fields are returned. This is the only transfer of Google user data outside the owner's own account. Anthropic's handling is governed by their own terms and privacy policy.
  • Nothing is sold, shared, or used for advertising, and no data is used to train any model.

What is stored locally

  • An OAuth token, so the tool does not have to ask for consent on every run.
  • A cache of extraction results, so the same receipt is not re-processed and re-billed.
  • Bank export CSVs and receipt files while a run is in progress.

All of this lives on the author's own machine and can be deleted at any time; deleting it causes the tool to ask for consent again and re-read the receipts.

Retention

Receipt files and the ledger are kept for as long as the owner keeps them, which is deliberately a long time — the purpose of the tool is to hold records for tax and audit purposes. They live in the owner's Drive and are deleted by deleting them there.

Limited Use

Receipts' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions, which immediately stops the tool from reading anything.
